# 吸顶标题上方信息流露出修复

2026-10-26 反馈：深色松烟入墨、樱花等多个主题滚动后，媒体或文字出现在“主页”吸顶标题上方；标题下沿还出现渐变透出。

原因：先前为面板预留了桌面 16px / 手机 8px 顶部间距，标题 sticky top 也相应偏移，但没有遮挡随文档滚动进入该空隙的信息流。原生标题下方的 40px 渐变又会部分显示媒体。仅设置标题背景并不能覆盖标题外的留白。

补丁位于共用 ColumnHeader 样式，不修改滚动结构或 JS：before 在标题背后覆盖顶部留白与圆角外围；标题自身保持不透明主题底色；after 改为细分隔线，不再覆盖渐变。保留既有标题高度、8px 圆角、16/8px 顶部位置、overflow:clip、文档滚动与点击返回顶部逻辑。饭否经典浅色的遮挡层复用其固定背景渐变，避免新色块接缝。

验证：Stylelint、完整生产构建与 diff 检查通过。Windows Edge 156 下加载实际皮肤和模块 CSS，以亮红媒体夹具滚动到标题背后，验证 12 款皮肤 × 深浅模式 × 1440/768/390 宽度，共 72 场景；顶部留白和圆角像素均与外部背景一致，无红色媒体露出，标题位置与分隔线正常。相同夹具对修复前产物会检测到顶部红色露出，验证能捕捉原问题。该验证是隔离布局夹具，不修改正式用户设置。
