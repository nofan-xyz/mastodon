# 页脚节日标记

正式站版本号右侧按北京时间（UTC+8）当天显示一个 emoji，其余日期留空。图标独立于源码链接，不可点击、不可聚焦，没有 title、悬浮文案或动画；它是纯装饰，不重复向屏幕阅读器朗读。

固定公历节日优先于农历和节气；同一天只显示一个图标。农历节日只认正常月份，不在闰月重复庆祝。

`useHolidayEmoji` 初始化时读取当前时间，设置下一次北京时间午夜的定时器。恢复窗口焦点、重新显示标签页、页面从往返缓存恢复时，也重新计算日期并调整定时器。卸载后清除定时器和事件监听。不新增网络请求，不使用账号资料或本地存储。

## 日历数据

`utils/holiday_calendar.json` 预先收录 2000–2100 年的六项变动日期，顺序为春节、元宵、端午、七夕、中秋、冬至。数值为 `月 × 100 + 日`，例如 `1222` 表示 12 月 22 日。公历节日直接按月日判断，不受该表年份范围限制；范围外的农历、节气标记安全留空。

数据由固定版本 `lunar-typescript@1.8.6`（MIT）离线生成。它仅作为开发依赖，日历库不会进入浏览器 bundle。生成命令：

```sh
node bin/generate-holiday-calendar.mjs
```

计算依据：[历法库源码](https://github.com/6tail/lunar-typescript)、[节气 API](https://6tail.cn/calendar/lunar.jieqi.html)。2026、2027 年样本与香港天文台[2026 年历](https://www.hko.gov.hk/en/gts/time/calendar/pdf/files/2026e.pdf)、[2027 年历](https://www.hko.gov.hk/en/gts/time/calendar/pdf/files/2027e.pdf)核对。

## 验证

自动测试覆盖全部 11 种标记、2026/2027 年农历日期、冬至的公历日期变化、闰月不重复、北京时间零点边界、跨午夜自动隐藏和切换、后台恢复及卸载清理。使用外地设备时区运行同一组测试，确认与设备所在时区无关。
