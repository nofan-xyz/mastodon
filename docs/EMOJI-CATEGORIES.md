# Beta 表情包分类栏易用性更新

2026-11-03 用户要求将正式站已经确认的表情分类栏改进一起发布到 Beta。本次基于已合并最新上游的 Beta 分支适配，不回退新发帖框、选择器容器及其图层修复，也不替换表情加载与缓存的 Beta 改进。

- 所有已选择的自定义分类显示代表表情图标，优先使用后台配置的 featured 封面，并始终使用静态图。
- 顶部导航支持桌面端按住鼠标左右拖动和触屏横向滑动；点击分类标签仍可切换分类。保留常用与系统 Emoji；分类提示使用真实名称，选中项自动滚入可视区域。
- 使用独立 category_order 保持用户保存的排列顺序，显示/隐藏序号不影响顺序；隐藏全部也清空旧分类。
- 仅悬停导航时显示细而浅的滚动条，移出隐藏，不引起布局跳动，保留触屏、滚轮与键盘操作。
- 设置页、搜索页和后台表情样式在所有主题共享加载，避免封面按原尺寸撑开。

复用正式站固定版本 emoji-mart-lazyload 3.0.1-j 的 Yarn 补丁，包含 ES/CommonJS 两入口；Beta 的分类排序保留其既有 Object.keys 后 sort 的兼容方式，分类标题字重保持 Beta 原样。API、状态和前端类型补充排序及封面字段；没有数据库迁移。

部署前重新执行相关类型、前端测试、Ruby 接口测试、构建，以及最终镜像隔离环境中的共库和浏览器验收。此前只包含上游合并的 22fc1ffbb5 镜像不会部署到生产。

本地验证：4276 项前端测试、309 项 Ruby 测试（包含分类选择和排序 API）通过，TypeScript、相关 ESLint/Stylelint/RuboCop、完整生产前端构建通过。Ruby 测试沿用进程级 OpenSSL 3.6.1 和独立本地数据库/Redis，未写入生产。保留 Beta 原有标题字重及分类 sort 兼容方式。最终镜像验收和部署结果随后单独记录。

最终镜像已经随 2026-11-04 Beta 更新部署，源码 cc0f26e072，完整验收和回退记录见 `docs/BETA_20261104_RELEASE.md`。
