# 自定义表情分类导航

表情选择器顶部为全部可见的自定义表情分组显示独立标签，优先使用管理后台设置的封面表情静态图片，无封面时取各组第一个可见表情。悬浮提示和可访问名称使用真实分组名称；未分类表情使用「自定义」。保留常用及全部标准 Emoji 分类。

导航按钮宽 44px，图标 32px；分组较多时横向滚动，桌面端可按住鼠标在快速分类栏左右拖动，触屏端保留原生滑动，并支持滚动条和键盘 Tab。选中状态与内容区域滚动同步，当前分类自动滚入导航可视区域，不滚动整页。搜索后点击分类沿用原组件的清空搜索与定位逻辑。

## 实现

`emoji-mart-lazyload` 原本只为第一个自定义分组显示 anchor，所有自定义分类共用星号图标。通过 Yarn patch 同时修正 ES 和 CommonJS 入口，固定原版本 `3.0.1-j`，避免修改 node_modules 或依赖浮动 latest。补丁保留原组件的分类索引和滚动事件，不改变表情内容。

`features/emoji/picker.ts` 提供额外的 `staticImageUrl`，保证用户开启 GIF 自动播放时导航仍使用静态缩略图；表情列表自身的动画偏好保持原行为。没有新增数据库字段或迁移。

参考检查：[rararwg/mastodon](https://github.com/rararwg/mastodon) 当前 main 的 picker 与样式未包含截图中的分类图标实现，本次基于正式站现有依赖完成。

## 个人选择和排序

沿用 `Wxw::EmojiPack.selection_for(current_user)`，API 只返回用户已选择的包；匿名访问使用管理员预设。新增可选 `category_order` 数值，使用 `picker_packs` 的用户保存顺序，与翻译名称和是否显示序号无关。前端通过 IndexedDB 保留该值，再用于内容和导航的共同排序。原先仅按分类名称排序，在用户隐藏序号时会丢失个人顺序；本次将顺序与标签解耦。

保留旧缓存不含排序值时的名称排序回退，并为新 API 格式调整 ETag，已有浏览器会重新获取数据。Redux 重新加载时替换旧选择，隐藏某包或隐藏全部后不会留下旧导航。封面使用 API 已有的 `featured` 标记。

## 表情包设置页主题修复

表情包管理、搜索和后台页面的专用样式通过所有基础主题共用的 `styles/_site-tweaks.scss` 引入。原先只在默认 `application.scss` 中引入，独立的饭否经典、太空饭否、朱砂印、Graphite 主题会缺失封面尺寸和列表布局。默认主题不再单独引入，避免主题间遗漏。已编译并用实际 CSS 检查全部 13 套皮肤的封面不超过 50px、列表横向布局、链接样式和 32px 拖动按钮；运行中的 Vite 也已返回修复后的饭否经典样式。
