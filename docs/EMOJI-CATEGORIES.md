# 自定义表情分类导航

表情选择器顶部为全部可见的自定义表情分组显示独立标签，以各组第一个表情的静态图片作为图标。悬浮提示和可访问名称使用真实分组名称；未分类表情使用「自定义」。保留常用及全部标准 Emoji 分类。

导航按钮宽 44px，图标 32px；分组较多时横向滚动，支持触屏滑动、滚动条和键盘 Tab。选中状态与内容区域滚动同步，当前分类自动滚入导航可视区域，不滚动整页。搜索后点击分类沿用原组件的清空搜索与定位逻辑。

## 实现

`emoji-mart-lazyload` 原本只为第一个自定义分组显示 anchor，所有自定义分类共用星号图标。通过 Yarn patch 同时修正 ES 和 CommonJS 入口，固定原版本 `3.0.1-j`，避免修改 node_modules 或依赖浮动 latest。补丁保留原组件的分类索引和滚动事件，不改变表情内容或 API。

`features/emoji/picker.ts` 提供额外的 `staticImageUrl`，保证用户开启 GIF 自动播放时导航仍使用静态缩略图；表情列表自身的动画偏好保持原行为。没有新增数据库字段或迁移。

参考检查：[rararwg/mastodon](https://github.com/rararwg/mastodon) 当前 main 的 picker 与样式未包含截图中的分类图标实现，本次基于正式站现有依赖完成。

## 验证

- 使用正式站公开 `/api/v1/custom_emojis` 的 1806 个表情，32 个分类均显示图标和名称。
- 实际依赖组件浏览器验收：逐个点击全部 32 个分类，核对可见标题、选中状态；验证插入回调、搜索无结果、搜索后点击分类清空搜索及常用入口。
- 1440、390、320px 视口无页面横向溢出，截图位于本地 `tmp/emoji-category-check/`。
- ESLint、Stylelint、TypeScript、格式及 diff 检查通过。

## 回退

应用旧正式站 Web 镜像并重新创建 web 服务；无需操作数据库。每次部署前记录原镜像与 compose override，并保留旧前端资源供未刷新的页面使用。
